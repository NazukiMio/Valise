N4 第二段：照看一台已经接入的服务器——改名、改用 Valise 通行证、更新 porter、换电脑后重装用户通行证——以及删除服务器。每一屏右边写着它来自哪里、需要什么登录、不做什么。确认后再写代码。

删除：只从这台电脑移除 / 移除并清理服务器 清理：逐项勾选 Agent 保护技能：默认不勾，写明不建议 备份库：一律保留，标“已删除的服务器” 连不上时：只能从这台电脑移除

3 · 改用 Valise 通行证 来自 SSH 配置的服务器

‹ nas · 设置

让 nas 改用 Valise 通行证

会做这些事
用你自己的 SSH 设置登录 nas 一次
装上用户通行证：只能查看和备份，拿不到 shell
核对它确实被限住（被执行了普通命令就立即撤掉，保持原样）
把你 known_hosts 里 nas 的指纹复制给 Valise
勾上才出现两栏管理口令（与添加服务器时相同）。
之后 Valise 不再用你的 SSH 钥匙连 nas。你自己的 ssh nas 照常能用，Valise 不改 ~/.ssh/config。
取消开始

说明

  • MigrateServer。每一步一行，进行中写当前子步骤与已等时间，可以停止（与添加服务器的“准备服务器”同一套）。
  • 服务器上还没有 porter 时，接着走 porter 部署（默认 Release，本地构建在“更多选项”）。
  • 经跳板机的服务器不画这一屏。
