B3 · 你自己在服务器上跑 sudo 命令，填回验证码

找回模式暂停：MCP 请求、自动复制、后台任务取消找回

在 home-vps 上运行这条命令

用你平时登录服务器的方式（ssh、控制台都行）。Valise 不会替你运行它，高级模式也不行：它要证明的就是“服务器上的你”。

sudo sh -c 'f=$(mktemp) && cat /home/me/.local/bin/valise-porter > "$f" && echo "45d82e75…c6cd $f" | sha256sum -c --quiet && chmod 700 "$f" && "$f" recovery-code --for me; r=$?; rm "$f"; exit $r'
复制命令这条命令会先把 porter 复制成只有 root 能改的副本，核对 SHA-256 一致才运行；对不上就什么都不做。
