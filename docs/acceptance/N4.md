## 1. 真实窗口试用（2026-11-08）

环境：本机开发构建（临时打成 `.app`，只为让操控工具识别；不是发布包），`--config-dir` 指向演练配置，连接 `ubuntu-vm`、`ubuntu-vm-x86`、`debian-vm`。操作由 Claude 通过 macOS 无障碍接口在后台完成。

### 1.1 通过

| 项 | 结果 |
| --- | --- |
| 首页读取 | 14 个 Agent，卡片视图；提醒卡片带「知道了」「带我去处理」 |
| 搜索 | 输入 `x86` 只剩该服务器上的 5 个；清除后恢复 |

### 1.2 发现并已修复

1. **本机备份按连接名匹配**：仓库里服务器目录用的是金库自己的名字（`debian-vm` 存在 `debian/` 下），界面按连接名找，`debian-vm` 上的 Agent 都显示“本机没有备份”并被算进“超过 7 天”的提醒。改为读 Agent 时顺带用日常钥匙读各服务器的金库名（`VaultStatus`），按它匹配；提醒从 6 个降到 4 个。
2. **自绘卡片没有按钮角色**：Agent 卡片、列表行、视图切换、导航窄栏、旅程节点在无障碍树里只有文字，读屏无法按下。加上按钮角色；名字带上 harness 与服务器，同名 Agent 可以区分。
3. **桌面版没接 Valise 口令框**：管理页令牌一步要确认是本人，服务层报“这里没法询问 Valise 口令”。已接上 `OwnerAuth`，与管理口令共用一个弹框，文案分开。
4. **健康页“定时备份：每 一次”**：保护计划按日历时间运行，没有固定间隔，文案拼空。改为“按保护计划的时间运行”。服务层文字，TUI 同样受益。
5. **未来时间说成“1 分钟前”**：模拟夏令时期间（时钟调到 2027 年）留下的备份，健康页说成“1 分钟前”。改为写出记录的日期并说明“晚于现在（备份时服务器时钟可能不准）”。
6. **搜索时计数不变**：改为“找到 N 个 · 共 M 个在用”。
7. **“超过 7 天”提醒不分原因**：补齐后仍有 4 个 Agent 报“没有新备份到这台电脑”，其实服务器上也没有新备份，“现在补到本机”解决不了。按用户决定（UI.md 7.2、7.3）分成两张卡片：服务器有更新的备份 →“有新备份还没复制到这台电脑”，去备份位置；服务器也没有 →“超过 7 天没有新备份”，去第一个 Agent 的“健康”看定时备份。服务器每个 Agent 的最新备份时间随读 Agent 时的金库状态一起读。实机复核：4 个都归到后者，进入 `debian-vm` 的 drill-synthetic 健康页签，显示“定时备份：没有开启”“备份：还没有备份”。
