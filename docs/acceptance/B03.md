## 2. 自动化证据

- `actionjournal`：分类（相对内部链接不列出、绝对内部链接、程序代码链接）；没有程序目录记录时拒绝并说明来源无法核实；指向其他位置与悬空链接拒绝并写明链接；暂存期间两类链接都只指向私有区域，还原后暂存摘要与活动目录一致；命令经链接写入私有副本时指出 `skills/program/cache.json`，原程序未被写入。
- `actiontxn`：含两类链接的完整事务发布，活动目录中链接为原文本；旧客户端（未声明 `link_handling`）在停服前被拒绝；步骤写入私有程序副本时不发布、恢复原服务，失败原因含“程序代码”。
- `actiontxn`（2026-11-07 续）：确认后新增的链接在停服后重读时被处理；指向外部的链接在任何服务调用前被拒绝；越界写入失败原因列出路径；`scratch` 区域内命令删掉暂存链接、新建指向程序目录与活动目录的绝对链接时发布成功，删掉的链接不被放回，指向活动目录的链接交换后可解析；新建指向暂存的链接时不发布、恢复原服务；审批读法重建 `scratch` 不判为改动配置；`scratch` 与 writes 重叠被拒绝。
